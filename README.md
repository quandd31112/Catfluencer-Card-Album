# Catfluencer Card Album Prototype

## Run in VS Code with Live Server
1. Open this folder in VS Code.
2. Install **Live Server** by Ritwick Dey.
3. Open `index.html`.
4. Click **Go Live** in the bottom-right.
5. It should open at `http://127.0.0.1:5500/`.

## Structure
- `index.html`
- `style.css`
- `app.js`
- `img/`
- `.vscode/`

Use image paths like:
`./img/set01/card01.webp`

This folder is also suitable for GitHub Pages.
